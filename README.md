### features

- custom dark color palette
- background image and transparency effects
- blur effects and smooth animations
- custom window controls and top bar
- separated chat bar and compact user panel

### installation

1. download [`CustomMidnight.css`](https://github.com/slynxxx/Custom-Discord-Theme-for-Vencord/blob/main/CustomMidnight.css).
2. open discord settings and navigate to **vencord → themes**.
3. open the themes folder and place `CustomMidnight.css inside it.
4. enable the theme and enjoy.
